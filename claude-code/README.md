# Claude Code

Anthropic이 만든 코딩 에이전트입니다. 터미널, IDE, 데스크톱 앱, 웹에서 코드를 읽고 고치고 명령을 실행합니다.

## 학습 목표

- [ ] 설치하고 첫 세션 실행하기
- [ ] 자주 쓰는 슬래시 명령어 익히기 (`/init`, `/clear`, `/compact` 등)
- [ ] `CLAUDE.md`로 프로젝트 규칙 알려 주기
- [ ] 권한 모드와 `settings.json` 설정 이해하기
- [ ] 훅(hooks)과 서브에이전트 써 보기
