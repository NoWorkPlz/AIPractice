# MCP (Model Context Protocol)

AI 모델이 외부 도구, 파일, 서비스에 접근할 수 있게 해 주는 표준 프로토콜입니다. MCP 서버를 연결하면 Claude 같은 클라이언트가 그 서버의 도구를 쓸 수 있습니다.

## 학습 목표

- [ ] 클라이언트, 서버, 도구(tools), 리소스(resources) 개념 이해하기
- [ ] Claude Code에 기존 MCP 서버 연결해 보기 (`claude mcp add`)
- [ ] 간단한 MCP 서버를 직접 만들어 보기 (Python 또는 TypeScript SDK)
