# 업무 리듬

일간·주간·격주·월간·분기 반복 업무를 한곳에서 정리하는 업무 관리 앱입니다.
PC 브라우저, 스마트폰 홈 화면 앱(PWA), 안드로이드 설치 파일(APK)로 쓸 수 있어요.

## 기능

- **오늘**: 오늘 할 일(주기별 묶음), 밀린 업무(완료/건너뛰기), 다가오는 업무(D-day), 다가오는 휴일, 날짜별 업무 메모
- **주간**: 월~일 7일 보드, 주차·공휴일 표시, 주간 진행률
- **월간**: 달력에 업무·공휴일 표시, 날짜를 누르면 그날 업무 체크
- **업무 관리**: 반복 업무 등록·수정·일시 중지·삭제
  - 일간 / 주간 / 격주: 요일·기준일 + 공휴일 처리(건너뛰기 · 직전 영업일로 당기기 · 그대로)
  - 월간 / 분기: 특정 일자 · 말일 · 첫 영업일 · 마지막 영업일, "주말·공휴일이면 직전 영업일로 당기기"
  - 일회성: 특정 날짜 하루
- **휴일 관리**: 대한민국 공휴일 2025~2027년 내장(대체공휴일, 선거일, 2026년부터 노동절·제헌절 포함), 회사 휴무일 직접 추가
- **매뉴얼로 업무 가져오기 (AI)**: 업무 매뉴얼 파일을 Claude·ChatGPT 앱으로 보내 분석하고, 답변을 붙여 넣으면 업무 후보로 보여주고 고른 것만 추가 (API 키 없이 쓰는 구독 그대로)
  - 지원 파일: PDF(스캔본 포함), 사진(JPG·PNG 등), 한글(HWP 5.x·HWPX), 워드(DOCX), 엑셀(XLSX), 파워포인트(PPTX), 텍스트(TXT·CSV·MD)
  - 문서 파일은 기기 안에서 글자를 뽑아 보내고, 글자가 거의 없는 스캔 문서는 안에 든 그림을 보냅니다
  - 암호가 걸린 한글 문서, 예전 오피스 형식(.doc·.xls·.ppt)은 PDF 등으로 저장해서 올려야 합니다
- **백업**: JSON으로 내보내기/가져오기 (PC ↔ 휴대폰 옮길 때)

## 스마트폰에서 쓰기

### 1) 홈 화면 앱 (아이폰·안드로이드 모두)

GitHub Pages로 공개하면 `https://<아이디>.github.io/<저장소>/` 주소가 생깁니다.

1. 저장소 **Settings → Pages** 에서 Source를 **Deploy from a branch**, 브랜치를 `main`(또는 이 작업 브랜치), 폴더를 `/ (root)`로 저장
2. 휴대폰에서 그 주소를 열고
   - 안드로이드: 크롬·삼성 인터넷 메뉴 → **홈 화면에 추가 / 앱 설치**
   - 아이폰: 사파리 공유 버튼 → **홈 화면에 추가**

설치하면 인터넷 없이도 열립니다(`sw.js` 오프라인 캐시).

### 2) 안드로이드 APK

`main` 또는 작업 브랜치에 푸시하면 GitHub Actions(`.github/workflows/android.yml`)가 APK를 만듭니다.

휴대폰에서 아래 주소를 열면 최신 APK가 바로 내려받아집니다 (로그인 불필요).

https://github.com/NoWorkPlz/AIPractice/releases/latest/download/work-rhythm.apk

설치할 때 "출처를 알 수 없는 앱" 허용이 필요합니다. 빌드 기록은 저장소의 **Releases**에서 볼 수 있어요.

직접 빌드하려면 Node 20+, JDK 21, Android SDK가 필요합니다.

```bash
npm ci
npm run build
npx cap add android   # 처음 한 번
npx cap sync android
cd android && ./gradlew assembleDebug
```

## 매뉴얼로 업무 가져오기

**기본: Claude·ChatGPT 앱으로 보내기 (API 키 불필요)**

1. **업무 관리 → 매뉴얼로 업무 가져오기** (오늘 화면의 바로가기 버튼으로도 열림)에서 **파일 선택**
   - 한글(HWP·HWPX)은 Claude·ChatGPT가 못 읽을 수 있어 앱이 텍스트로 바꿔서 보냅니다
2. **AI 앱으로 보내기** → 공유 창에서 Claude 또는 ChatGPT 선택 → 자동 복사된 요청 문구를 입력칸에 붙여넣고 전송
   - 공유 창이 안 뜨는 기기(PC 일부 브라우저)는 claude.ai / chatgpt.com을 열고 파일을 직접 첨부
3. 답변의 JSON 코드 블록을 복사하고 앱으로 돌아와 **복사한 답변 붙여넣기** → 후보 확인 → **선택한 업무 추가**
   - 안드로이드 앱은 돌아오면 복사한 답변을 자동으로 읽어 옵니다

**선택: API 키로 앱 안에서 바로 분석**

1. [console.anthropic.com](https://console.anthropic.com)에서 API 키를 발급하고 결제 수단을 등록합니다.
2. 같은 화면의 **API 키로 앱 안에서 바로 분석**을 펼쳐 키를 저장합니다. 키는 그 기기에만 저장되고 백업 내용에는 들어가지 않습니다.
3. 파일을 고른 뒤 **위 파일로 바로 분석**.

- 보낸 파일 내용은 고른 AI 서비스(Anthropic·OpenAI)로 전송됩니다. 회사 보안 규정을 먼저 확인하세요.
- API 키 방식의 사용료는 분량에 따라 다르며, 수십 쪽 매뉴얼 기준 보통 수백 원 수준입니다. 결과 화면에 대략적인 금액이 표시됩니다.
- Claude 미리보기(아티팩트) 화면에서는 외부 연결이 막혀 있어 이 기능이 동작하지 않습니다. 설치한 앱이나 GitHub Pages 주소에서 쓰세요.
- 브라우저용 SDK는 `vendor/anthropic-sdk.mjs`에 묶여 있습니다. 새 버전으로 바꾸려면 `package.json`의 `@anthropic-ai/sdk` 버전을 올리고 `npm run vendor`를 실행하세요.

## 참고

- 데이터는 각 기기(브라우저/앱)에만 저장됩니다. 기기끼리 자동 동기화되지 않으니 백업으로 옮기세요.
- 2028년 이후 공휴일은 `index.html`의 `HOLIDAYS` 목록에 추가하거나, 앱의 휴일 관리에서 직접 추가하세요.
- 앱 파일을 바꾼 뒤에는 `sw.js`의 `CACHE` 버전을 올려야 설치된 앱이 새 버전을 받습니다.
