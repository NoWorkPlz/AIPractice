# 업무 리듬

일간·주간·격주·월간·분기 반복 업무를 한곳에서 정리하는 업무 관리 앱입니다.
설치 없이 `index.html`을 브라우저로 열면 바로 쓸 수 있어요.

## 기능

- **오늘**: 오늘 할 일(주기별 묶음), 밀린 업무(완료/건너뛰기), 앞으로 2주간 다가오는 업무(D-day), 날짜별 업무 메모
- **주간**: 월~일 7일 보드, 주차 표시, 주간 진행률
- **월간**: 달력에 업무 표시, 날짜를 누르면 그날 업무 체크
- **업무 관리**: 반복 업무 등록·수정·일시 중지·삭제
  - 일간: 요일 선택 (기본 평일)
  - 주간: 요일 여러 개 선택
  - 격주: 기준일부터 2주마다
  - 월간: 특정 일자 / 말일 / 첫 영업일 / 마지막 영업일, "주말이면 직전 금요일로 당기기"
  - 분기: 분기 첫째·둘째·마지막 달 + 월간과 같은 날짜 규칙
  - 일회성: 특정 날짜 하루
- **백업**: JSON으로 내보내기/가져오기 (다른 PC로 옮길 때)

## 참고

- 데이터는 브라우저 `localStorage`에만 저장됩니다. 브라우저 데이터를 지우기 전에 내보내기로 백업해 두세요.
- 영업일 계산은 주말만 제외하며, 공휴일은 반영하지 않습니다.
- 처음 열면 예시 업무가 들어 있습니다. 화면 상단의 "예시 업무 지우기"로 한 번에 지울 수 있어요.
