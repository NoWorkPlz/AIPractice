# AIPractice

Claude Code, Codex, MCP, 스킬, 플러그인, 옵시디언 같은 AI 도구 사용법을 공부하고 실습한 내용을 모아 두는 저장소입니다.

## 폴더 구성

| 폴더 | 주제 |
| --- | --- |
| [claude-code/](claude-code/) | Anthropic의 터미널 기반 코딩 에이전트 Claude Code |
| [codex/](codex/) | OpenAI의 코딩 에이전트 Codex |
| [mcp/](mcp/) | 모델에 외부 도구와 데이터를 연결하는 Model Context Protocol |
| [skills/](skills/) | Claude가 필요할 때 불러 쓰는 작업 지침 묶음, 스킬 |
| [plugins/](plugins/) | 명령어, 에이전트, 훅, MCP 서버를 한데 묶어 배포하는 플러그인 |
| [obsidian/](obsidian/) | 마크다운 기반 노트 앱 옵시디언과 AI 도구 연동 |

## 학습 계획

1. **Claude Code 기본기**: 설치, 기본 명령어, `CLAUDE.md`, 권한 설정 익히기
2. **Codex 비교**: 같은 과제를 Codex로도 해 보고 차이점 정리하기
3. **MCP**: 기존 MCP 서버를 연결해 보고, 간단한 서버를 직접 만들어 보기
4. **스킬**: 반복하는 작업을 스킬로 만들어 보기
5. **플러그인**: 만든 스킬, 명령어, MCP 서버를 플러그인으로 묶어 보기
6. **옵시디언**: 공부한 내용을 옵시디언 노트로 정리하고 AI 도구와 연결해 보기

## 기록 방법

- 주제별 폴더 안에 날짜나 소주제 이름으로 노트(`.md`)와 예제 코드를 둡니다.
- 각 폴더의 `README.md`에는 그 주제의 학습 목표와 진행 체크리스트를 둡니다.
