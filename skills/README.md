# 스킬 (Skills)

`SKILL.md` 파일에 작업 방법을 적어 두면, Claude가 관련된 일을 할 때 그 지침을 불러와 따릅니다. 반복하는 작업 방식을 재사용할 수 있게 해 줍니다.

## 학습 목표

- [ ] `SKILL.md`의 구조(frontmatter의 `name`, `description`, 본문) 이해하기
- [ ] 스킬이 어디에 저장되고 언제 불려 오는지 알아보기
- [ ] 반복하는 작업 하나를 골라 스킬로 만들어 보기
